# n8n Automation Skill

## Mô tả
Kỹ năng kích hoạt các quy trình tự động hóa thông qua n8n để phân phối nội dung đa kênh.

## Chỉ dẫn
- Sử dụng các Webhook được cấu hình trong n8n để đẩy bài viết lên các nền tảng: X, Facebook, YouTube.
- Đảm bảo định dạng dữ liệu gửi qua Webhook đúng chuẩn mà workflow n8n yêu cầu.
- Kiểm tra phản hồi từ n8n để xác nhận bài viết đã được đăng thành công.
- Lưu lại lịch sử đăng bài để tránh trùng lặp nội dung.
