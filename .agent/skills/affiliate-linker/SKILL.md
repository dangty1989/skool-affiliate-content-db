# Affiliate Linker Skill

## Description
Tự động chèn link affiliate và CTA vào bài viết để tối ưu hóa chuyển đổi cho Skool Affiliate.

## Instructions
- Quét nội dung bài viết để xác định các điểm "nóng" (hotspots) có thể chèn link.
- Chèn link affiliate vào ít nhất 2 vị trí mang tính chất gợi ý giải pháp.
- Luôn thêm phần CTA ở cuối bài với cấu trúc: [Lợi ích cực lớn] + [Link Affiliate].
- Đảm bảo tỷ lệ CTA/Giá trị không quá 20%.
