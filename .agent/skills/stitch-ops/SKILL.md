# Stitch Ops Skill

## Mô tả
Kỹ năng sử dụng Google Stitch để thực hiện các thao tác hệ thống, quản lý file và cài đặt môi trường chuyên nghiệp.

## Chỉ dẫn
- Sử dụng Google Stitch để chạy các lệnh CLI khi cần cài đặt thư viện hoặc công cụ mới.
- Quản lý cấu trúc file hệ thống, đảm bảo mọi thứ gọn gàng và tuân thủ kiến trúc Agentic.
- Tự động hóa các tác vụ lặp lại trong terminal để tiết kiệm thời gian vận hành dự án.
- Luôn kiểm tra trạng thái lệnh sau khi thực hiện để đảm bảo không có lỗi xảy ra.
